# Примеры

## Тесты для бенчмарков

- bottles99.b - печатает стихотворение 99 bottles
- mandelbrot.b - печатает множество Мандельброта
- bench.b - печатает английский алфавит странным способом

## Идиомы на брейнфаке

- flagged_exec_*.b - демонстрирует идиому с блоками, работающими при включенном флаге

## Части кода, которые можно использовать

- parts/if.b - это if (не while), не изменяет проверяемое значение
- parts/ifnot.b - это if not (не while not), не изменяет проверяемое значение
- parts/move_until.b - позволяет перемещать указатель ленты до ближайшей ячейки с определенным значением
- parts/array_human.b - реализация массива, запись и чтение по индексу
- parts/stack_human.b - реализация стека, запись и чтение верха стека, много комментариев, мало примеров
- parts/stack.b - реализация стека, запись и чтение верха стека, мало комментариев, много примеров

## Полноценный каркас проекта

- jump_human.b - полноценная структура проекта с возможностью реализации jump, call, функций, более подробная информация
  в самом файле
- https://codeberg.org/IvanSakaev/RISC-BF - автоматический генератор кода из risc-v, поддерживаются очень многие
  функции, многобайтовые операции, jump, call и т.д. Вынесено в отдельный проект для удобства. Активно дорабатывается

## Реализации массивов

- arrays/addressing-A.b - Доступ к элементу массива медленный с помощью циклического смещения всех элементов. Можно
  реализовать быстрый доступ к элементам рядом, но пока такого нет. 1 ячейка - 1 элемент.
- arrays/addressing-B.b - Нуждается в описании. 2 ячейки - 1 элемент.
- arrays/addressing-C.b - Доступ к элементам довольно быстрый. Используется перемещение ячеек с данными по массиву.
  Когда они доходят до нужной ячейки, значение записывается/читается, потом ячейки с данными возвращаются обратно.
  1 ячейка - 1 элемент.
- arrays/addressing-C-stack[-human].b - Реализация стека, основанная на addressing-C.b
